# BFC Competitor Check 2026

## Project objective

Analyze competitors in the Philippine coffee, beverage, and related
food markets to identify opportunities for But First, Coffee.

Compare verified historical evidence from 2024 with evidence collected
in 2026 wherever comparable information is available.

## Research scope

1. Company profiles and franchise models
2. Branch locations and store formats
3. Menu, pricing, and product value
4. Promotions and loyalty programs
5. Café design and customer experience
6. Customer reviews from accessible platforms
7. Digital ordering and delivery channels
8. Franchise investment and support
9. Commercial opportunities and recommendations

## Project structure

| Folder | Contents |
| :--- | :--- |
| data/raw | Original collected data |
| data/processed | Cleaned datasets |
| notebooks | Analysis workflow |
| sql | Database structure and queries |
| reports/figures | Exported charts |
| references | Sources and research guidelines |
